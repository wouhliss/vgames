## Hard constraints

- **Nothing runs unless its bytes are pinned:** a runtime archive is used only if the catalog that names it
  verified under the compiled-in key, and its SHA-256 matched **before** extraction; size checked while
  downloading. Extraction uses the package path-safety rules (no `..`, no absolute paths, no links out of the
  target, no device files).
- **Highest catalog version per catalog key** (F2), never globally. A catalog older than the highest seen for
  that key is refused.
- Compat profiles: `verify_compat_profile` under the server's trust state; keep the highest revision; launcher-
  owned variables (`WINEPREFIX`, `PROTONPATH`, `STEAM_COMPAT_*`, …) can never come from a profile or a manifest.
- Release builds use only the compiled-in catalog key. A debug-only override (`VGAMES_RUNTIME_CATALOG_URL` and a
  test key, like `VGAMES_PROFILE`) exists for tests and is compiled out of release builds.
- No polling: refresh the catalog on startup, on server switch and before a compat launch (at most every 6 h,
  timestamp-based, not a timer).
