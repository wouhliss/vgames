# Phase-2 agent status files

The live files are `ins.md`, `play.md`, `game.md` and `int.md`, using AGENTS.md §6's headings plus
`Built for you`. Each owner records only interfaces and work actually on main, links its evidence,
and adopts any notes another slice wrote before it started. Phase-1 `agent-1.md` through
`agent-5.md` are frozen historical records.

Before each task, read all four live files. Missing interfaces are built under phase-2 README §1
and noted in the owner's `Built for you` section; preserve these notes and extend them.

Under `In progress`, use `Ready for INT: #<PR>` for security changes needing INT's review.
Under `Blockers / contract questions`, record `contract ack: #<PR>` or an objection for breaking
contracts. If an additive contract merged under README §3a before INT started, record
`Merged without INT: #<PR>` so INT can review it and fix forward. No status note waits on a person.
